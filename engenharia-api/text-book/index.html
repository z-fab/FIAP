Do Notebook à Produção

Engenharia de software para Data Science & APIs de inferência. Quatro capítulos que levam seu modelo de uma célula de notebook bagunçada até um pacote testado, servido por uma API e pronto para produção — usando o dataset California Housing como fio condutor.

4 capítulos · ~55 min de leitura · Intermediário · + pasta codigos/ para a prática
Capítulo 01
Do Notebook à Produção: Refatoração & Pipeline
Transforme código de notebook em módulos src/ limpos com SOLID, e encapsule o pré-processamento num Pipeline reprodutível.
~16 min
Capítulo 02
Testes Automatizados em ML
Escreva uma suíte de testes que dá confiança no pipeline: unitários com pytest, schema com pandera e smoke tests.
~13 min
Capítulo 03
APIs de Inferência com FastAPI
Exponha o modelo como API REST: validação com Pydantic, endpoints /predict e /health, logging, latência e padrões de serving.
~15 min
Capítulo 04
Empacotamento e Tooling Profissional
Configure o projeto como pacote reutilizável com uv, ruff, taskipy e Makefile, e versione modelo + API juntos.
~11 min
